# External kernel sources

Pinned research trees are fetched here only by
`tools/mid1020l-fetch-sources.sh`. Every source is isolated in its own
subdirectory with `.source-url` and `.source-commit` markers. Existing
subdirectories are never overwritten by the script.

These are references, not presumed-compatible dependencies. Review each tree's
license, exact commit and device differences before extracting or redistributing
any code. The source trees are deliberately not committed into this project.
